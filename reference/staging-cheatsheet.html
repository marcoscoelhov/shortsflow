Staging sem confusão

Use esta folha para decidir onde uma mudança ou job deve rodar.

Três lugares, três responsabilidades

LugarServe paraNão deve
LocalEditar, revisar e executar testes rápidos.Renderizar ou guardar segredos.
StagingValidar na VPS com isolamento e providers reais.Usar banco ou artefatos da produção.
ProduçãoExecutar jobs aprovados e preservar continuidade operacional.Receber código experimental diretamente.

Algoritmo de decisão

  1. É apenas edição, lint ou teste rápido? Use o computador local.
  2. Usa provider real, mídia ou comportamento ainda não promovido? Use staging.
  3. O código passou pelas verificações e está aprovado? Promova para produção.
  4. A VPS está indisponível? Pare e mostre o erro. Não use CPU local silenciosamente.

Frase para lembrar: staging ensaia com condições reais; produção apresenta para o público.
